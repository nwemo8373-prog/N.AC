📂 بيانات المشروع

ابدأ بمعلومات التطبيق ومصدر ملفات الموقع.

STEP 01
أحرف إنجليزية صغيرة وأرقام ونقاط فقط.
اختيار الرابط يعني أن محتوى الموقع سيحتاج الإنترنت؛ الصور البعيدة لن تصبح محلية تلقائيًا.
لأفضل نتيجة: اجعل index.html في جذر ZIP. هذه الواجهة لا ترفع ملفاتك إلى Firebase Storage.

🧠 مساعد AI

فحص إرشادي للإعدادات قبل البناء.

هذا الفحص المدمج يعتمد على قواعد محلية، وليس اتصالًا بنموذج ذكاء اصطناعي خارجي. يمكن ربط API لاحقًا من خادم آمن.

🎨 تصميم التطبيق

خصص مظهر التطبيق وسلوكه على الهاتف.

STEP 02

🖼️ سياسة الملفات والصور

الصور تُضمّن ضمن المشروع ولا تحتاج إلى استضافة صور منفصلة.

سيتم نسخ محتويات ZIP إلى assets/www داخل مشروع Android. لا تستخدم روابط صور خارجية إذا كنت تريد أن تكون كل الصور داخل APK. لا يتم رفع ZIP إلى Firebase.
تنبيه: إذا كان المشروع يعتمد على API أو فيديوهات خارجية أو صور برابط بعيد، فهذه الموارد لن تصبح محلية تلقائيًا. حجم APK سيزداد كلما زاد حجم الصور والملفات.

🛡️ صلاحيات Android

فعّل ما يحتاجه موقعك فقط؛ Android سيطلب إذن المستخدم وقت الاستخدام عند الحاجة.

STEP 03
تحديد الصلاحية لا يمنحها تلقائيًا. يجب أن يطلب التطبيق الإذن من المستخدم، وأن يكون الموقع يستخدم الميزة بالفعل. لا نضيف صلاحيات غير ضرورية.

🔔 إعداد الإشعارات

اختر تذكيرات محلية أو جهّز الإشعارات الفورية من خادم.

STEP 04

نوع الإشعار

التذكير المحلي يعمل على جهاز المستخدم. الإشعارات الفورية الجماعية تحتاج FCM وخادمًا موثوقًا، والإشعار المستمر يحتاج خدمة Android مناسبة.

محتوى الإشعار

ربط الإشعارات بكود الموقع

لا تضع مفاتيح FCM السرية أو مفاتيح Admin داخل HTML. يجهّز هذا النموذج الإعدادات فقط؛ يجب توفير endpoint آمن للإرسال الفوري.

الإشعارات غير مفعّلة.

🏗️ فحص وبناء APK

راجع الإعدادات ثم أرسل المشروع إلى خدمة بناء Android.

STEP 05
جاهز للفحص. اختر ZIP صالحًا واضبط الإعدادات قبل البناء.
لم يتم الفحص بعد.

اتصال خدمة البناء

لا يمكن للمتصفح إنشاء APK بنفسه؛ يجب توفير خادم بناء يشغّل Android SDK وGradle.
لا تستخدم سرًا إداريًا أو مفتاح Firebase هنا. رمز المتصفح يمكن استخراجه؛ الأفضل أن يمر عبر بوابة موثوقة.

حفظ إعدادات المشروع في Firebase (اختياري)

الرابط الذي أرسلته hedars-ai.firebaseapp.com هو نطاق تطبيق/استضافة Firebase، وليس بالضرورة رابط قاعدة البيانات. انسخ Database URL من صفحة Realtime Database في Firebase Console.

يتطلب هذا النموذج إعداد قواعد أمان صحيحة، وتسجيل الدخول إذا كانت القواعد تشترطه. لا تجعل قاعدة البيانات مفتوحة للقراءة والكتابة العامة.

ملحوظة: تنزيل APK وتثبيته خطوتان منفصلتان. بعد التنزيل، افتح الملف على Android ووافق على التثبيت إذا طلب النظام ذلك. نجاح البناء لا يُثبت تلقائيًا أن كل وظائف الموقع تعمل على كل الأجهزة.
